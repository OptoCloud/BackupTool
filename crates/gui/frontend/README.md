# backuptool GUI

Desktop frontend for backuptool, built with Tauri 2, SvelteKit, and TypeScript.

```sh
pnpm install
pnpm tauri dev      # run in development
pnpm tauri build    # produce installers
pnpm check          # type-check
```

Recommended editor setup: [VS Code](https://code.visualstudio.com/) with the [Svelte](https://marketplace.visualstudio.com/items?itemName=svelte.svelte-vscode), [Tauri](https://marketplace.visualstudio.com/items?itemName=tauri-apps.tauri-vscode), and [rust-analyzer](https://marketplace.visualstudio.com/items?itemName=rust-lang.rust-analyzer) extensions.
